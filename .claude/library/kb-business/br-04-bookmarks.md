# BR-04 — Bookmarks (Salvar questão / Salvos)

A bookmark saves a question to the permanent **Salvos** list. It is a durable, cross-session
library of questions the student wants to revisit.

1. Bookmarking is independent of any test run: it survives the session and appears in Salvos.
2. It is NOT "come back to it later in this test" — that is [BR-03](br-03-postpone.md).
3. It is NOT saved test progress — that is [BR-05](br-05-save-quit-test.md).
4. Bookmarking never affects score, statistics or the SM-2 schedule.
